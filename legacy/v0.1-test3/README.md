# Archived v0.1-test3 helper scripts

These two CMD scripts are preserved for historical reference only. They were originally created for **v0.1-test3 x64**, before the universal selector existed.

- `03-Open-Sync-Status.cmd` directly opens Edge using the old isolated profile path and a hard-coded program location.
- `04-Restore-Instructions.cmd` describes how to stop the original test Hook and clean up the old isolated profile.

**Do not mix these helpers with v0.3-test7.** For the current release, use the root `03-Diagnose-Architecture.cmd`, `04-Check-Package.cmd`, and `07-How-To-Stop.cmd` from the complete v0.3-test7 ZIP.
