# v0.2-test3 变更记录（多语言测试构建）

- 检测 Windows **用户界面显示语言**，为简体中文、繁體中文或 English 选择菜单与状态信息，其余语言回退英文。
- 增加 `--lang=zh-CN`、`--lang=zh-TW`、`--lang=en` 翻译覆盖参数，方便跨语言测试。
- 菜单、启动日志、错误提示、状态说明、原有配置确认、备份提示与恢复指南均提供三语文本。
- 主程序通过 Unicode 输出；CMD 改用 ASCII，不再依赖固定的简体中文代码页。
- 独立测试配置模式和原有 Edge 配置模式均保留，Hook DLL 延续之前的版本，**本次未修改 Hook 算法**。
- 头像加载异常留待后续版本修复。

**测试状态：** 前版 v0.2-test2 已由用户确认两种模式都能同步；v0.2-test3 多语言构建尚须在 Windows 7 上验证语言检测、提示字体、备份与同步回归。该版本尚未创建 GitHub Release。
